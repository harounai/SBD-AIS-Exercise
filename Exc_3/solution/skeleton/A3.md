# Exercise 03 — PostgreSQL Container Setup and Multi-Stage Docker Build (SBD Course)

1. Synced the forked GitHub repository to get all files related to Exercise 03.

2. Pulled the PostgreSQL 18 image:
   ```bash
   docker pull postgres:18
   ```

3. Created a `debug.env` file containing:
   ```
   POSTGRES_DB=order
   POSTGRES_USER=docker
   POSTGRES_PASSWORD=docker
   POSTGRES_TCP_PORT=55432
   DB_HOST=127.0.0.1
   ```
   The port `55432` was chosen to avoid conflicts with the locally installed PostgreSQL service on `5432`.

4. Created a persistent Docker volume for database data:
   ```bash
   docker volume create pgdata_sbd
   ```

5. Started a new PostgreSQL container:
   ```bash
   docker run -d \
     --name pgdb_sbd \
     --env-file debug.env \
     -p 55432:5432 \
     -v pgdata_sbd:/var/lib/postgresql/18/docker \
     postgres:18
   ```

   - The container name `pgdb_sbd` links it clearly to the SBD course.  
   - The custom port `55432` prevents interference with any local PostgreSQL instance.

6. Verified connectivity via `psql`:
   ```bash
   psql -h localhost -p 55432 -U docker -d order
   ```
   Confirmed tables `drinks` and `orders` were automatically created and prepopulated by the Go application.

7. Implemented database prepopulation in `ex3/db.go` under `prepopulate()`:
   - Added default drinks and sample orders linked by `DrinkID`.

   ```go
   drinks := []model.Drink{
   ```

8. Loaded environment variables manually before running the app for testing:
   ```bash
   env $(cat debug.env | xargs) go run main.go
   ```

9. Verified successful DB connection and prepopulation in pgAdmin 4 and via CLI.

10. **Created a multi-stage Dockerfile** to containerize the Go application:

    ```dockerfile
    # ======================
    # Stage 1 — Builder
    # ======================
    FROM golang:1.25 AS builder
    WORKDIR /app
    COPY . .
    RUN chmod +x scripts/build-application.sh && ./scripts/build-application.sh

    # ======================
    # Stage 2 — Runtime
    # ======================
    FROM alpine:latest
    WORKDIR /app
    COPY --from=builder /app/ordersystem /app/ordersystem
    EXPOSE 3000
    CMD ["/app/ordersystem"]
    ```

    - Stage 1 uses `golang:1.25` to compile the Go binary with the provided script.  
    - Stage 2 uses `alpine` as a lightweight runtime image.  
    - The compiled binary `/app/ordersystem` is copied from the builder stage.

11. Built the final image:
    ```bash
    docker build -t orderservice .
    ```

12. Verified the runtime container starts correctly:
    ```bash
    docker run --rm -p 3100:3000 orderservice
    ```
    Output:
    ```
    INFO Order System starting
    INFO Connecting to database
    environment variable 'POSTGRES_USER' is not set
    ```
    This confirmed the binary runs successfully inside the Alpine runtime image.

13. **Created a Docker network and connected both containers:**
    ```bash
    docker network create sbdnet
    docker network connect sbdnet pgdb_sbd
    ```

14. **Updated the environment configuration** to connect over the Docker network:
    ```
    POSTGRES_DB=order
    POSTGRES_USER=docker
    POSTGRES_PASSWORD=docker
    POSTGRES_TCP_PORT=5432
    DB_HOST=pgdb_sbd
    ```

15. **Ran the Orderservice container with environment variables and network:**
    ```bash
    docker run --rm \
      --name orderservice \
      --env-file debug.env \
      --network sbdnet \
      -p 3100:3000 \
      orderservice
    ```

    Output:
    ```
    INFO Order System starting
    INFO Connecting to database
    INFO Database prepopulated with sample drinks and orders
    ```

     The application now connects to the PostgreSQL container and prepopulates data automatically.
